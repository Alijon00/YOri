# Ёрӣ — правила проекта

## Что это
Сайт помощи ребёнку (13–17 лет), столкнувшемуся с опасностью в интернете: шантаж, слив фото, травля, незнакомый взрослый, взлом аккаунта. Сайт ведёт от «что случилось» к шагам, службам помощи и объяснению «что будет после звонка». Есть режим для взрослых. Команда localhost:404.

## Жёсткие требования (никогда не нарушать)
- Работает на дешёвых Android-телефонах и при слабом интернете.
- Полностью офлайн после первого открытия (PWA).
- Таджикский и русский языки.
- Не собирает персональные данные: нет регистрации, аналитики, трекеров; ничего не отправляется на сервер; текст из поля «напиши своими словами» никогда не покидает устройство.
- Ребёнок пользуется сам: кнопки не меньше 44px, простой язык, тон без осуждения («ты не виноват(а)»).
- ИИ только выбирает маршрут, все советы написаны людьми. Если ИИ не уверен — не угадывает, а показывает варианты и службы помощи.
- Никаких внешних запросов в рантайме: шрифты, иконки, модель — локальные файлы.

## Структура
- /web — фронтенд: Vite + React 18 + TypeScript (strict), TSX
- /data — tokenizer-cases.json (тесты токенизатора), позже phrases.csv
- /reference — готовый прототип (источник текстов, дизайна, шрифтов, иконок). Только читать, не изменять.
- /ml — C# обучение классификатора (ПОЗЖЕ, сейчас не создавать)
- /api — C# сервер контента (ПОЗЖЕ, сейчас не создавать)

## Токенизатор (одинаковый в TS и будущем C#, проверяется тестами из data/tokenizer-cases.json)
1. lowercase; «ё» → «е»;
2. разбить по всему, что не буква Unicode;
3. отбросить слова короче 2 букв;
4. каждое слово обрезать до первых 5 букв;
5. добавить биграммы соседних обрезанных слов в виде «a_b».

## Стиль
- TypeScript strict, функциональные компоненты, без any.
- Комментарии на русском.
- Семантическая разметка (настоящие button и a), видимый фокус, контраст текста не ниже 4.5:1.
- Не добавлять библиотеки без необходимости.
- После каждой задачи: npm run build без ошибок.
